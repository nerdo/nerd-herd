    nerd-herd Agents mod: sessions by status, space and group

    nerd-herd is a set of Herdr mods, and its full scope is not settled yet. This spec covers one of them: an Agents mod that replaces the sidebar’s Agents section, keeps Herdr’s two ways to sort agents and adds a third that gives each Spaces group its own section with status folders inside, leads each session’s card with its title, wraps long subjects instead of cutting them off, renames sessions with Herdr’s own rename, keeps a finished session under Done until Dannel deals with it, and lets each Spaces group look different in Agents and in Spaces. The Spaces mod has its own spec.

    Stage
    finalized
    Complexity
    5 / 10 — one mod, a session list model with three arrangements, Spaces’ group headers reused, Herdr commands it already offers, and a Done record kept as herdr-core labels
    Sequence
    Built after the Spaces mod, whose groups and group header the Agents mod reuses (Agents grouping)
    Herdr version
    0.1.16 (app), read from /Applications/Herdr.app/Contents/Info.plist
    Toolchain
    TypeScript on Bun, compiled by bun build into the mod’s main.js, the same as the Spaces mod.
    Standing rule
    Where Herdr already provides a feature, use it, unless the idea does not fit it (from the user, 2026-11-16).
    Design reviewer Implementation lead Test reviewer

    Narrative

    Dannel opens the Herdr sidebar and sees each running agent session with its title first and its space and machine after it, its full subject wrapped onto more lines, renames one session from its card and sees the new name in the card and in Herdr’s tab bar, and clicks a card to focus that session’s pane.

    Reading and renaming sessions

    Claims
    1. Sorting by Priority shows Blocked, Done, Working and Idle sections, and each card names its space and machine
    2. Grouped by space shows one section per space, and each card names its machine
    3. Grouped by group shows one section per Spaces group, drawn the way Spaces draws that group, with Blocked, Done, Working and Idle folders inside
    4. The new sort choice is named with the word Spaces uses for a group
    5. A group nested inside another group gets its own section, whose header names the group it sits inside
    6. Spaces outside every group show under Ungrouped, after the groups
    7. Folding a section or folder in Agents leaves Spaces as it was
    8. A card shows the agent's icon, then the session's title in bold before anything else
    9. A session card shows the session's subject wrapped onto more lines when it is longer than one line
    10. Renaming a session from its card gives its Herdr tab that name
    11. Renaming a session to an empty name returns it to its automatic name
    12. Clicking a session card focuses that session's pane

    Dannel has three agent sessions running: one on desk-client working on "THRD: Reset leader election", one on this computer fixing a Python virtual environment, and one on desk-home about NAS hardware. Today the Agents section shows them in one list, cut off at the right edge, with the machine's name in tiny text.

    With nerd-herd, every card starts with the agent’s icon and the session’s title in bold, so the thing that tells two sessions apart comes first. The menu behind the clock icon still offers Herdr’s two choices. Under Priority, Agents shows Blocked, Done, Working and Idle sections, and each card names its space and machine after the title, so the two sessions called "sandbox" are told apart by machine. Under Grouped by space, each space has its own section, and a card names only its machine, since the section already names the space.

    Dannel wants to look at one client’s work only, so they pick the new choice, which reads “Grouped by folder” because folder is what their Spaces settings call a group. Each Spaces group now has its own section, drawn as Spaces draws it: the townsquare banner, the orange banner, or a plain folder. Inside each section are Blocked, Done, Working and Idle folders holding that group’s sessions, and each card names its space and machine. The Clients group, which sits inside Work in Spaces, gets its own section whose header says it is inside Work. Spaces in no group show under Ungrouped, last. Dannel folds the Work section to quiet it, and Spaces still shows Work open.

    One session still has a vague automatic subject, so they rename it "NAS drive health" from its card, and the card and the Herdr tab bar both show the new name. Later they clear the name, and the session goes back to its automatic name. They click a card, and Herdr focuses that session's pane.

    Keeping finished sessions until they are dealt with

    Claims
    1. A session that finishes a turn shows under Done
    2. Opening a Done session and leaving it keeps it under Done
    3. Dismissing the focused Done session moves it to Idle
    4. Replying to a Done session moves it to Working, and its next finished turn shows under Done again
    5. A session dismissed in one Herdr window shows as dismissed in every Herdr window connected to its machine

    The desk-client session finishes its turn on "THRD: Reset leader election" while Dannel is reading in another tab, and it shows under Done. Dannel means to click the NAS session but clicks the desk-client one, sees the wrong session, and clicks away. Today, Herdr would count that click as having dealt with it and move it to Idle, where it gets lost. With nerd-herd it stays under Done, because looking at a session is not dealing with it.

    Later Dannel opens the desk-client session on purpose and reads what the agent did. It needs no reply, so they press the dismiss key, or click the purple Dismiss button in the middle of the status bar at the bottom of the window, and the session moves to Idle. The NAS session is also under Done; Dannel types a follow-up question to that agent instead, and the session moves to Working. When the agent answers, it shows under Done again.

    That evening Dannel opens Herdr on another computer connected to desk-client. The desk-client session is still under Idle there, and anything still waiting under Done on this computer is waiting there too, because the record of what was dismissed is kept on the machine the session runs on.

    Showing a group differently in Agents and Spaces

    Claims
    1. A group can show as a banner in Agents and as a folder in Spaces, or the other way round
    2. A group's Agents look follows its Spaces look until a different look is picked for Agents
    3. A group can have a second banner style, with its own open and folded images, that either panel can show
    4. A panel set to a banner style the group has no image for shows the group as a folder
    5. In Agents, a banner group shows its folded image while its Agents section is folded

    Dannel wants running client work to stand out. In the townsquare group's settings, under Spaces, they set Spaces to show the group as a folder and Agents to show its banner. Spaces now lists townsquare as a folder with its icon, and in Agents' Grouped by folder view townsquare's section carries the full banner above its status folders. Their other groups were never changed, so they show in Agents the same way they show in Spaces.

    For the frankenstein group they want a quieter banner in Spaces and the big one in Agents. They add a second banner style, with its own open and folded images, and set Spaces to show the second style and Agents the first. When they fold frankenstein's section in Agents, Agents shows that style's folded image, while Spaces keeps its own fold. A group set to the second style before it has any second image shows as a folder until one is added.

    Questions

    Skeleton sentence

    Question
    Does the narrative’s skeleton journey say what “it works” means for the Agents mod?
    Resolution
    Yes (the user, 2026-11-20: “it works”). Its wording about sessions sitting under their machine was updated to the title-first cards resolved the same day.

    Session rename scope

    Question
    Is renaming a session Herdr's own rename, or a name only this mod shows?
    Resolution
    Herdr's own tab rename (the tab.rename command), so the name shows everywhere Herdr shows that tab.

    Agents grouping

    Question
    How is the Agents list organized?
    Resolution
    Herdr’s sort menu keeps its two choices and their stored values in the shared value agents.sort: Priority (priority) and Grouped by space (grouped). nerd-herd adds a third, Grouped by group (groups), named with the word the Spaces settings use for a group. It gives each Spaces group a section drawn as Spaces draws it (folder or banner, at the banner’s own size), with Blocked, Done, Working and Idle folders inside. There is no machine and space tree in Agents (the user, 2026-11-20: “in grouped mode, the status becomes like a folder”; “I kind of want to preserve the same values and just add our concepts to it”). Herdr’s own Agents mod reads an unknown value as Priority, so switching back to it is safe.

    Card contents

    Question
    What does a session’s card show?
    Resolution
    The agent’s icon, then the title in bold, then the location that the sections above it do not already give: space and machine under Priority and Grouped by group, the machine only under Grouped by space. This extends the rule in Herdr’s Agents mod, where a card names its space only when no header above it does (the user, 2026-11-20: “keep the agent icon”).

    Nested groups

    Question
    In Grouped by group, where do sessions of a group nested inside another group go?
    Resolution
    Into the nested group’s own section, whose header names the group it sits inside (the user, 2026-11-20: “go with the rest of the recommendations”).

    Fold sharing

    Question
    Does folding a section in Agents fold that group in Spaces?
    Resolution
    No. Agents keeps its own folded or open state for each group section and each status folder (the user, 2026-11-20).

    Group color

    Question
    Does a group get a color that Agents shows on cards?
    Resolution
    Not in this spec. The color stripe and the Group color field are left out to keep the start simple (the user, 2026-11-20: “get rid of the thin color stripe concept for a start”).

    Group look per panel

    Question
    Can a group look different in Agents and in Spaces, and where is that set?
    Resolution
    Yes, set in the group's settings under Spaces: one “Show as” choice for Spaces and one for Agents. Banner links and the icon stay shared; the choice only decides what each panel draws (the user, 2026-11-20: “I might want to have the large banners only show up under agents … while the spaces display using folders/icons … or vice versa”).

    Look choices

    Question
    What can each panel's Show as choice be?
    Resolution
    Banner, Second banner, or Folder. The folded image belongs to a banner style as its folded state, never as a look of its own, so a group can have a second banner style with its own open and folded images (the user, 2026-11-20: “the folded banner is meant for state, not a variation … let's add a second banner style that can be used but has the open/folded states”). A banner choice with no image for that style shows the folder.

    Agents default

    Question
    What does an existing group's Agents look start as?
    Resolution
    “Same as Spaces”, a fourth choice for Agents only and its default, so nothing changes until Dannel picks a look for Agents (the user, 2026-11-20: “recommended for the other questions”).

    Other settings per panel

    Question
    Does anything besides the look differ between the panels?
    Resolution
    No. The fold chevron, the banner's controls and their colors stay shared (the user, 2026-11-20).

    Header size

    Question
    Are bigger, higher-contrast section and machine headers part of this mod?
    Resolution
    No. Headers keep Herdr’s current size (11 to 11.5 pixel text) for now.

    Leaving Done

    Question
    What moves a session out of Done? Herdr moves it to Idle as soon as its pane is focused, so a wrong click loses it.
    Resolution
    Two deliberate acts, never looking: Dannel dismisses it, or Dannel replies and it goes back to Working (the user, 2026-11-19: “I want a more deliberate way to move things out of done”).

    Where the Done record lives

    Question
    Where is the record of which finished turns were dismissed kept, so every Herdr window shows the same Done list?
    Resolution
    On the machine the session runs on, as a label on the session's terminal in that machine's herdr-core (hc label <terminal> nerd-herd.handled=<turn>), the way Herdr keeps its own herdr.seen label. Every Herdr window that connects to that machine reads the same label (the user, 2026-11-19: “the state should probably live on the server that the session belongs to”). Seen 2026-11-19 with hc get --json: a terminal carries turn and a herdr.seen label; Herdr showed it as done where herdr.seen (11) was below turn (13), and as idle where the two were equal.

    Seen marker

    Question
    Should a Done session Dannel has opened look different from one Dannel has not opened?
    Resolution
    Not in this spec. A wrong click would mark it seen, and a time-based rule would still be error-prone (the user, 2026-11-19: “I would pause on that”).

    Dismiss button placement

    Question
    Where does the Dismiss button go?
    Resolution
    In the center of the status bar at the bottom of the window, the bar that ends with the command palette hint, shown only while the focused session is under Done. It has a color, so it does not blend into the grey bar; purple was suggested (the user, 2026-11-19: “Put the button on the status bar at the bottom … maybe in the center though and give it a color so it isn't just grey and blends in (purple?)”).

    How Dismiss gets into the status bar

    Question
    The status bar is drawn whole by Herdr's workspace-status mod, or by the jj mod's jj-status where jj is installed. How does a nerd-herd button get into its center?
    Resolution
    nerd-herd ships its own status bar mod: the status mod that scripts/installLayout.ts picks, with patch files in patches/ that add Dismiss in its center, applied the way scripts/vendor-spaces.ts applies the Spaces patches. The install names it in the status block in place of the original. An upstream change then shows up as a patch that no longer applies. A request for a center slot in the status mods can be filed upstream beside it (the user, 2026-11-19: “go with your recommendations”).

    Dismiss color

    Question
    Which purple does Dismiss use?
    Resolution
    The theme's magenta, theme().ansi5, so it stays purple-ish and follows light and dark themes (the user, 2026-11-19: “go with your recommendations”).

    Dismiss key

    Question
    Which key dismisses the focused session, and does a nerd-herd key reach the mod while a terminal has the keyboard?
    Resolution
    Checked in ~/.config/herdr-app/keys.json on 2026-11-19. A mod section's keys, such as mod:nerd-herd-spaces with plain up and down, act only while that mod has the keyboard, so they cannot reach Dismiss while a terminal is focused. The global section is where keys that work over a terminal live (⇧⌘P for the command palette is one). On macOS a terminal program never receives ⌘ keys, and cmd-e is bound in neither the global nor the terminal section. So Dismiss is cmd-e, bound in the global section to the status bar mod's dismiss command, which the mod reads with nextCommand(). Not yet observed: that a global binding reaches a mod's nextCommand(). The first test of the dismiss key checks it, and a failure there reopens this question (the user, 2026-11-19: “go with your recommendations”).

    Starting point for the Done record

    Question
    A session with no nerd-herd.handled label yet, such as every session on the day nerd-herd is installed: which of its finished turns count as dealt with?
    Resolution
    Every turn Herdr counts as seen (herdr.seen), so installing nerd-herd does not fill Done with old sessions (the user, 2026-11-19: “go with your recommendations”).

    A turn that finishes while Dannel watches

    Question
    When a session finishes its turn while its pane is focused, does it go under Done?
    Resolution
    Yes. Watching a turn finish is still only looking, so it waits under Done until dismissed or replied to (the user, 2026-11-19: “go with your recommendations”).

    Testing against the shared herdr-core

    Question
    How do the walks check Done, dismiss, and reply, when every test window shares the person's real herdr-core and the walks may not create or change real sessions?
    Resolution
    Unit tests over the Done ledger with recorded terminal data, and the dismiss command checked by the label call it sends. The real label write on a real session is a hand walk that Dannel runs (the user, 2026-11-19: “go with your recommendations”).

    Process Flow

    Module Definitions

    Session list model

    Responsibility
    Arranges Herdr's agents for the chosen sort (Priority, Grouped by space, or Grouped by group) into sections, status folders and cards, and picks each card's text.
    Owns
    Sections, folders, card order and card text.
    Delegates
    Nothing. Data in, data out.
    Input Agent[], Space[], groups, sort
    Herdr's agents and spaces, nerd-herd's saved Spaces groups and group word, the sessions under Done from Done ledger, and the value of agents.sort.
    Output AgentsRow[]
    The sections, folders and cards to draw.

    Group looks

    Responsibility
    Stores each group's second banner style and its Show as choice for Spaces and for Agents, and answers what a panel draws for a group: a banner style's open or folded image, or the folder.
    Owns
    The new saved group fields, their defaults for groups saved before them, and the two Show as fields and second banner links in group settings.
    Delegates
    Loading banner images to the existing banner cache; drawing to the Spaces group header (src/mod/groupHeaderView.ts).
    Input SavedGroup, panel, folded
    A saved group, which panel is drawing it, and whether it is folded in that panel.
    Output GroupLook
    A banner image link, or the folder with the group's icon.

    Agents sidebar mod

    Responsibility
    Draws the Agents sections and cards and turns clicks into Herdr commands.
    Owns
    Layout, wrapping, the rename control, the sort menu, and the folded state of each section and folder.
    Delegates
    Arranging to Session list model; drawing a group's header to the Spaces group header (src/mod/groupHeaderView.ts); renaming to Herdr tab.rename; focusing to Herdr pane.focus; which sessions are under Done to Done ledger.

    Done ledger

    Responsibility
    Decides which sessions are under Done: a session that is not working and whose finished turn is above the turn its nerd-herd.handled label records.
    Owns
    The rule for Done, and the starting point for a session with no label.
    Delegates
    Nothing. Data in, data out.
    Input terminals()
    Herdr's core terminals: address, status, turn, and labels.
    Output Set<address>
    The sessions under Done.

    Dismiss control

    Responsibility
    Shows Dismiss in the center of the status bar, in purple, while the focused session is under Done, and handles the dismiss key.
    Owns
    The button, the cmd-e binding, the label it writes, and the nerd-herd status bar mod with its patches over the chosen status mod.
    Delegates
    Whether the focused session is under Done to Done ledger; storing the dismissal to herdr-core, through hc label <terminal> nerd-herd.handled=<turn>.

    Validation Boundaries
    • Herdr’s agents, spaces, and terminals come typed from herdr.d.ts. An agent’s title is text the agent chose, so the card shows it as text and never interprets it.
    • A session name typed by the user goes to Herdr’s tab.rename, which owns its rules; an empty name returns the tab to its automatic name.
    • The nerd-herd.handled label is external data: another Herdr window, another nerd-herd version, or a hand edit with hc label may have written it. Done ledger reads it as a whole turn number; any other value counts as no label.
    • The agents.sort value is shared with Herdr’s own Agents mod and any other mod. A value other than priority, grouped or groups counts as priority, as Herdr’s mod does.
    • Saved groups written before this spec have no look fields and no second banner. Group looks reads a missing or unknown Spaces look as today’s rule (the banner when the group has one, else the folder), and a missing or unknown Agents look as Same as Spaces.

    Ambiguity Resolution

    "Session" means a Herdr tab that runs an agent. Herdr's Agents section already labels each row from its tab name when the tab is named, so renaming a session means renaming its tab (tab.rename), which also follows the standing rule to use Herdr's own features.

    The shipped agents mod belongs to Herdr. Herdr’s guide says to copy shipped mods with mod.clone before changing them, so nerd-herd’s Agents mod goes into a copied layout and the user’s main layout stays as it is.

    "Done" in this spec means a session that finished a turn Dannel has not dealt with, by dismissing it or replying. Herdr's own done means a session that finished while nobody was looking at it, and it ends when someone looks. The Agents mod shows nerd-herd's meaning under the Done header. Herdr's done and idle both feed it, and its Idle header holds the rest.

    End-to-end tests share the harness the Spaces spec researches (its question “End-to-end test harness”).
