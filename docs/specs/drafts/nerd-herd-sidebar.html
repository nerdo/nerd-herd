    nerd-herd: a clearer Herdr sidebar

    nerd-herd is a pair of Herdr mods that replace the sidebar's Spaces and Agents sections. Spaces gains groups that gather machines (for example Personal and Work). Agents lists each machine's sessions under that machine, with subjects that wrap instead of being cut off. The first build is the Spaces mod with groups; the Agents mod comes after it. This draft needs answers to the open questions in Questions before it can be finalized.

    Narrative

    Dannel renames the sidebar's word for groups to "Environments", makes a Work environment with an emoji icon, drags desk-work and This computer into it, sorts and folds the environments, and after Herdr restarts sees those machines' spaces still inside the folded Work environment in their custom order.

    Organizing machines into groups

    Claims
    1. The new-group button in Spaces adds an empty group that Dannel names
    2. Dropping a machine on a group lists that machine's spaces inside the group
    3. Dropping a machine between two machines puts it at that position
    4. Choosing alphabetical or reverse alphabetical sorts machines by name, and choosing custom again restores the dragged order
    5. Folding a group hides its machines and keeps its header with the group's name and machine count
    6. A group shows its chosen icon and banner in its header
    7. Groups, their machines, the order, the fold state, and the look are the same after Herdr restarts
    8. An unreachable machine stays in its group and says it is unreachable
    9. This computer can be dropped into a group like any machine
    10. Groups have their own sort, custom by default, with alphabetical and reverse alphabetical as the other choices
    11. Deleting a group moves its machines to the ungrouped machines below the groups
    12. Ungrouped machines show below the groups with no header, or under a header when that setting is on
    13. Changing the word for groups to Environments shows Environments wherever the sidebar names groups

    Dannel works on a personal machine and on machines for two contexts: their own projects and their job at Job. The Spaces section lists five machines in name order, so personal and work machines are mixed together. They click the new-group button beside the Spaces "+" button, and a group appears with its name ready to edit. They type "Work" and pick an icon for it.

    They drag desk-work from the list and drop it on the Work group. The machine and its spaces now sit inside Work. They make a Personal group the same way, drop desk-home and ai-sandbox into it, and drag ai-sandbox above desk-home. Later they switch the sort to alphabetical to find a machine by name. Then they switch back to custom, and their dragged order returns.

    When they focus on personal work, they fold Work. Its header stays, showing "Work" and how many machines it holds. laptop-travel is switched off today, and it stays in Personal marked as unreachable. The next morning Herdr restarts after an update, and the sidebar shows the same groups, order, folds, and icons as the evening before.

    "Groups" is not quite how Dannel thinks of these, so they change the sidebar's word for them to "Environments". The new-group button, the headers, and the menus now say "environment" instead. They drag This computer into Personal too, because it is a personal machine like the others. They try a temporary "Scratch" environment, holding ai-sandbox, then delete it; ai-sandbox moves down to the ungrouped machines below the environments. Last, they set the environments to sort alphabetically, so Personal shows above Work, while the machines inside each one keep their own sort.

    Reading and renaming sessions by machine

    Claims
    1. Agents lists each session under the machine it runs on
    2. A session row shows the session's subject wrapped onto more lines when it is longer than one line
    3. Renaming a session from its row gives its Herdr tab that name
    4. Renaming a session to an empty name returns it to its automatic name
    5. Clicking a session row focuses that session's pane

    Dannel has three agent sessions running: one on desk-client working on "THRD: Reset leader election", one on this computer fixing a Python virtual environment, and one on desk-home about NAS hardware. Today the Agents section shows them in one list, cut off at the right edge, with the machine's name in tiny text.

    With nerd-herd, Agents shows a header for each machine and the sessions running there beneath it. The desk-client session's full subject, "π 🧵 THRD: Reset leader election", wraps onto a second line instead of ending in "…". The two sessions both called "sandbox" are easy to tell apart because each sits under its own machine.

    One session still has a vague automatic subject, so they rename it "NAS drive health" from its row, and the row and the Herdr tab bar both show the new name. Later they clear the name, and the session goes back to its automatic name. They click a row, and Herdr focuses that session's pane.

    Questions

    Spec or build order

    Question
    Is this design worked out in a spec, or built straight from the request?
    Resolution
    A spec in docs/specs/, because the design still needs back and forth.

    How machines are put in groups

    Question
    How does a machine get assigned to a group?
    Resolution
    All in the sidebar: a new-group button beside the Spaces "+", drag and drop to move and reorder machines, a sort choice of custom, alphabetical, or reverse alphabetical, collapsible groups, an icon and a banner per group, all kept by Herdr so it survives restarts.

    Session rename scope

    Question
    Is renaming a session Herdr's own rename, or a name only this mod shows?
    Resolution
    Herdr's own tab rename (the tab.rename command), so the name shows everywhere Herdr shows that tab.

    Group icon source

    Question
    Where does a group's icon come from?
    Resolution
    An emoji for now. The saved icon records its kind (emoji today), so icon sets such as the Noun Project can be added later as another kind without changing saved emoji icons.

    Group nomenclature

    Question
    What does the sidebar call a group?
    Resolution
    "Groups" by default, changeable by the user (for example "Environments" or "Projects"). The code always says "group"; every word shown to the user comes from settings data.

    Changing the group word

    Question
    Where does the user change the word for groups, and does the setting hold a singular and a plural form?
    Context
    The sidebar needs both forms: "Environments" as a header and "New environment" on the button. English plurals are irregular ("Property", "Properties"), so deriving one form from the other fails for some words.
    Options
    • A settings popup opened from the Spaces header, with separate singular and plural fields
    • The same popup, with one field and the plural made by adding "s"
    • Hand-edited settings only, no popup
    Recommendation
    A settings popup with singular and plural fields, which can also hold the ungrouped-header switch.

    Ungrouped header wording

    Question
    When the ungrouped-header setting is on, what does that header say?
    Options
    • "Ungrouped", fixed
    • Built from the group word, for example "No environment"
    • A third word the user sets
    Recommendation
    Built from the group word, so a changed word changes it too.
    Related
    Changing the group word: the setting form decides which word is available.

    Group banner source

    Question
    Where does a group's banner come from?
    Context
    Herdr's guide documents mods showing images from files under ~/.config/herdr-app. Showing an image straight from a web link is not documented, so a link may need to be downloaded to a file first.
    Options
    • A web link (URL)
    • A file on this computer
    • A colored band instead of an image
    Recommendation
    A colored band for the first build, images after.

    Group nesting

    Question
    Can a group hold other groups?
    Options
    • No, one level only
    • Yes, groups inside groups
    Recommendation
    One level only.

    Sort scope

    Question
    Does the machines' sort choice apply to every group at once, or does each group get its own?
    Context
    Groups have their own sort, separate from the machines' sort (see Group order under sorting). This question is about the machines inside groups.
    Options
    • One machine sort for every group
    • One machine sort per group
    Recommendation
    One machine sort for every group.

    One sorting concept

    Question
    Are the group sort and the machine sort two features, or one?
    Resolution
    One. A single sort order (custom, alphabetical, reverse alphabetical) works on any list of named items, so groups and machines use it now and sessions can use it later.

    Group order under sorting

    Question
    When the sort is alphabetical, are the groups themselves also sorted by name, or only the machines inside them?
    Resolution
    Groups have their own sort, separate from the machines' sort: custom (the order the user arranges) by default, alphabetical, or reverse alphabetical.

    Machines outside any group

    Question
    Where does a machine that is in no group show, including a machine added later?
    Resolution
    Below the groups with no header by default. A setting puts them under a header instead.

    Deleting a group

    Question
    What happens to a group's machines when the group is deleted?
    Resolution
    They move to the ungrouped machines below the groups.

    This computer in groups

    Question
    Where does "This computer" go now that groups exist?
    Resolution
    It is treated like any other machine: the user groups it however they like.

    Agents grouping

    Question
    How is the Agents list organized?
    Options
    • One header per machine; groups ignored
    • Group, then machine, then sessions, matching Spaces
    • Herdr's two existing views, plus this as a third choice in its sort menu
    Recommendation
    Group, then machine, then sessions.
    Waits on
    The Agents mod, which comes after the first build.

    First build scope

    Question
    Which mod is built first?
    Resolution
    The Spaces mod with groups. The Agents mod comes after it.

    Header size

    Question
    Are bigger, higher-contrast section, group, and machine headers part of the first build?
    Resolution
    No. Headers keep Herdr's current size (11 to 11.5 pixel text) for now.

    Group storage scope

    Question
    Is it enough that groups are kept on this computer only?
    Resolution
    Yes. Herdr's built-in shared mod state, saved to ~/.config/herdr-app/shared.json on this computer.

    End-to-end test harness

    Question
    Can a second, isolated Herdr window run beside the real one so the whole mod is tested without touching the real window or its settings?
    Context
    Herdr documents HERDR_APP_HOME for selecting a different settings folder and running window, herdr-app do for running commands, and herdr-app shot for screenshots. Its manual says never to automate the mouse or keyboard on the person's real display. Whether two app instances run at once is not documented. This is research for the walking skeleton phase, not a choice for the user.

    Source language

    Question
    Is the mod written as JavaScript checked against Herdr's type files, or as TypeScript compiled to JavaScript?
    Resolution
    TypeScript on Bun, the user's usual setup, compiled by bun build into the mod's main.js.

    Process Flow

    Module Definitions

    Group model

    Responsibility
    Turns saved groups, the group sort, the machine sort, and Herdr's machine list (this computer included) into the ordered rows Spaces shows, and applies a group action to saved groups.
    Owns
    Group membership, custom order of groups and of machines, sort rules, fold state, where ungrouped machines go.
    Delegates
    Ordering to Sort order. Otherwise data in, data out. It never holds a display word: rows name groups by id, and Spaces sidebar mod picks the words.
    Input SavedGroups, Machine[], GroupAction
    The saved groups, Herdr's machines, and one action (make, rename, delete, move, reorder, fold, sort groups, sort machines, set icon).
    Output SavedGroups, SpacesRow[]
    The new saved groups, and the rows to draw.

    Session list model

    Responsibility
    Groups Herdr's agents under the machine they run on and picks each row's subject text.
    Owns
    Grouping and row text.
    Delegates
    Nothing. Data in, data out.
    Input Agent[], Space[]
    Herdr's agents and spaces.
    Output AgentsRow[]
    The rows to draw.

    Saved group store

    Responsibility
    Reads and writes saved groups through Herdr's shared state.
    Owns
    The shared-state key and the check that what was read has the expected shape.
    Delegates
    Saving to Herdr (shared and setShared).
    Input unknown
    Whatever is stored under the key.
    Output SavedGroups
    Checked saved groups.

    Sort order

    Responsibility
    Orders any list of named items by one sort choice: custom (the order given), alphabetical, or reverse alphabetical.
    Owns
    The sort choices and how each one orders items.
    Delegates
    Nothing. It knows names and order, not groups or machines.
    Input SortChoice, Named[]
    A sort choice and items, each with a name, in their custom order.
    Output Named[]
    The same items in the chosen order. The custom order itself is never changed.

    Sidebar settings

    Responsibility
    The one typed, validated place for user-changeable sidebar settings, each with one default declared beside it.
    Owns
    The word for groups (default "Group" and "Groups"), whether ungrouped machines get a header (default off), and the settings' shared-state key.
    Delegates
    Saving to Herdr (shared and setShared).
    Input unknown
    Whatever is stored under the settings key.
    Output SidebarSettings
    Checked settings with every default applied.

    Spaces sidebar mod

    Responsibility
    Draws the Spaces rows and turns clicks and drops into group actions.
    Owns
    Layout, drag and drop, the new-group button.
    Delegates
    Rules to Group model; saving to Saved group store; display words to Sidebar settings; space commands to Herdr.

    Agents sidebar mod

    Responsibility
    Draws the Agents rows and turns clicks into Herdr commands.
    Owns
    Layout, wrapping, the rename control.
    Delegates
    Grouping to Session list model; renaming to Herdr tab.rename; focusing to Herdr pane.focus.

    Validation Boundaries
    • Saved groups read from Herdr's shared state are external data: another mod, a hand edit, or an older nerd-herd version may have written them. Saved group store checks their shape on every read. What happens to data that fails the check is not decided yet.
    • Herdr's machines, spaces, and agents come typed from herdr.d.ts. A group may name a machine Herdr no longer lists, so Group model treats a missing machine as data, not an error.
    • Group names and icons typed by the user are checked when entered. Limits (length, allowed characters) are not decided yet. An icon is saved with its kind, and the only kind accepted today is emoji.
    • Sidebar settings read from Herdr's shared state are external data too. Sidebar settings checks them on every read and fills each missing value from its one declared default.

    Ambiguity Resolution

    "Session" means a Herdr tab that runs an agent. Herdr's Agents section already labels each row from its tab name when the tab is named, so renaming a session means renaming its tab (tab.rename), which also follows the standing rule to use Herdr's own features.

    "Stored with Herdr" means Herdr's shared mod state, which Herdr saves to ~/.config/herdr-app/shared.json on this computer and loads at start (Group storage scope).

    "Machine" means any machine Herdr lists, this computer included. The code never says "remote": most machines are remote, but this computer is a machine like the rest, and the user groups this computer like any other (This computer in groups). Herdr leaves out temporary machines, and so does nerd-herd.

    "Group" is the code's word. The word the user sees comes from Sidebar settings, "Groups" by default, so a test that checks displayed text supplies its own settings rather than relying on the default.

    The shipped spaces and agents mods belong to Herdr. Herdr's guide says to copy them with mod.clone before changing them, and to copy a layout with layout.clone, so nerd-herd's mods go into a copied layout and the user's main layout stays as it is.
