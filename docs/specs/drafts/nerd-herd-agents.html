    nerd-herd Agents mod: sessions by machine

    nerd-herd is a set of Herdr mods, and its full scope is not settled yet. This spec covers one of them: an Agents mod that replaces the sidebar’s Agents section, lists each session under the machine it runs on, wraps long subjects instead of cutting them off, renames sessions with Herdr’s own rename, and keeps a finished session under Done until Dannel deals with it. The Spaces mod has its own spec. This draft needs answers to the open questions in Questions before it can be finalized.

    Narrative

    Dannel opens the Herdr sidebar and sees each running agent session under the machine it runs on, with its full subject wrapped onto more lines, renames one session from its row and sees the new name in the row and in Herdr’s tab bar, and clicks a row to focus that session’s pane.

    Reading and renaming sessions by machine

    Claims
    1. Agents lists each session under the machine it runs on
    2. A session row shows the session's subject wrapped onto more lines when it is longer than one line
    3. Renaming a session from its row gives its Herdr tab that name
    4. Renaming a session to an empty name returns it to its automatic name
    5. Clicking a session row focuses that session's pane

    Dannel has three agent sessions running: one on desk-client working on "THRD: Reset leader election", one on this computer fixing a Python virtual environment, and one on desk-home about NAS hardware. Today the Agents section shows them in one list, cut off at the right edge, with the machine's name in tiny text.

    With nerd-herd, Agents shows a header for each machine and the sessions running there beneath it. The desk-client session's full subject, "π 🧵 THRD: Reset leader election", wraps onto a second line instead of ending in "…". The two sessions both called "sandbox" are easy to tell apart because each sits under its own machine.

    One session still has a vague automatic subject, so they rename it "NAS drive health" from its row, and the row and the Herdr tab bar both show the new name. Later they clear the name, and the session goes back to its automatic name. They click a row, and Herdr focuses that session's pane.

    Keeping finished sessions until they are dealt with

    Claims
    1. A session that finishes a turn shows under Done
    2. Opening a Done session and leaving it keeps it under Done
    3. Dismissing the focused Done session moves it to Idle
    4. Replying to a Done session moves it to Working, and its next finished turn shows under Done again
    5. A session dismissed in one Herdr window shows as dismissed in every Herdr window connected to its machine

    The desk-client session finishes its turn on "THRD: Reset leader election" while Dannel is reading in another tab, and it shows under Done. Dannel means to click the NAS session but clicks the desk-client one, sees the wrong session, and clicks away. Today, Herdr would count that click as having dealt with it and move it to Idle, where it gets lost. With nerd-herd it stays under Done, because looking at a session is not dealing with it.

    Later Dannel opens the desk-client session on purpose and reads what the agent did. It needs no reply, so they press the dismiss key, or click Dismiss above the session's pane, and the session moves to Idle. The NAS session is also under Done; Dannel types a follow-up question to that agent instead, and the session moves to Working. When the agent answers, it shows under Done again.

    That evening Dannel opens Herdr on another computer connected to desk-client. The desk-client session is still under Idle there, and anything still waiting under Done on this computer is waiting there too, because the record of what was dismissed is kept on the machine the session runs on.

    Questions

    Skeleton sentence

    Question
    Does the narrative’s skeleton journey say what “it works” means for the Agents mod?

    Session rename scope

    Question
    Is renaming a session Herdr's own rename, or a name only this mod shows?
    Resolution
    Herdr's own tab rename (the tab.rename command), so the name shows everywhere Herdr shows that tab.

    Agents grouping

    Question
    How is the Agents list organized?
    Options
    • One header per machine; groups ignored
    • Group, then machine, then sessions, matching Spaces
    • Herdr's two existing views, plus this as a third choice in its sort menu
    Recommendation
    Group, then machine, then sessions.

    Header size

    Question
    Are bigger, higher-contrast section and machine headers part of this mod?
    Resolution
    No. Headers keep Herdr’s current size (11 to 11.5 pixel text) for now.

    Leaving Done

    Question
    What moves a session out of Done? Herdr moves it to Idle as soon as its pane is focused, so a wrong click loses it.
    Resolution
    Two deliberate acts, never looking: Dannel dismisses it, or Dannel replies and it goes back to Working (the user, 2026-11-19: “I want a more deliberate way to move things out of done”).

    Where the Done record lives

    Question
    Where is the record of which finished turns were dismissed kept, so every Herdr window shows the same Done list?
    Resolution
    On the machine the session runs on, as a label on the session's terminal in that machine's herdr-core (hc label <terminal> nerd-herd.handled=<turn>), the way Herdr keeps its own herdr.seen label. Every Herdr window that connects to that machine reads the same label (the user, 2026-11-19: “the state should probably live on the server that the session belongs to”). Seen 2026-11-19 with hc get --json: a terminal carries turn and a herdr.seen label; Herdr showed it as done where herdr.seen (11) was below turn (13), and as idle where the two were equal.

    Seen marker

    Question
    Should a Done session Dannel has opened look different from one Dannel has not opened?
    Resolution
    Not in this spec. A wrong click would mark it seen, and a time-based rule would still be error-prone (the user, 2026-11-19: “I would pause on that”).

    Dismiss button placement

    Question
    Where on the main pane does the Dismiss button go? The user wants it on the main pane rather than on the sidebar row (2026-11-19).
    Context
    The nerd-herd layout's work column holds the tabs bar, then the focused pane. A nerd-herd block can be added to that column.
    Options
    • A thin bar between the tabs bar and the pane, shown only while the focused session is under Done: “Finished. Dismiss”
    • A Dismiss button at the end of the tabs bar, shown only while the focused session is under Done
    Recommendation
    The thin bar: it says why the button is there, and it does not move the tabs.

    Dismiss key

    Question
    Which key dismisses the focused session, and does a nerd-herd key reach the mod while a terminal has the keyboard?
    Context
    Keyboard access is required (the user, 2026-11-19). nerd-herd's keys live in their own section of keys.json; whether that section's keys fire while a terminal pane is focused has not been checked.
    Recommendation
    Check how Herdr routes a mod section's keys first, then pick a key that no terminal program uses.

    Starting point for the Done record

    Question
    A session with no nerd-herd.handled label yet, such as every session on the day nerd-herd is installed: which of its finished turns count as dealt with?
    Options
    • Every turn Herdr counts as seen (herdr.seen): what is Idle today stays Idle, and only what Herdr shows as done starts under Done
    • No turn: every session that ever finished a turn starts under Done
    Recommendation
    Every turn Herdr counts as seen, so installing nerd-herd does not fill Done with old sessions.

    A turn that finishes while Dannel watches

    Question
    When a session finishes its turn while its pane is focused, does it go under Done?
    Context
    Herdr's own type file says done means “it finished while you weren't looking”, so Herdr shows such a session as Idle straight away.
    Options
    • Yes: it waits under Done until dismissed or replied to, like any finished turn
    • No: a turn Dannel watched finish counts as dealt with
    Recommendation
    Yes. Watching a turn finish is still only looking.

    Testing against the shared herdr-core

    Question
    How do the walks check Done, dismiss, and reply, when every test window shares the person's real herdr-core and the walks may not create or change real sessions?
    Options
    • Unit tests over the Done ledger with recorded terminal data, and the dismiss command checked by the label call it sends; the real label write is a hand walk
    • A test-only session the person allows the walks to create and label
    Recommendation
    Unit tests plus a hand walk, unless the person allows a test-only session.

    Process Flow

    Module Definitions

    Session list model

    Responsibility
    Groups Herdr's agents under the machine they run on and picks each row's subject text.
    Owns
    Grouping and row text.
    Delegates
    Nothing. Data in, data out.
    Input Agent[], Space[]
    Herdr's agents and spaces.
    Output AgentsRow[]
    The rows to draw.

    Agents sidebar mod

    Responsibility
    Draws the Agents rows and turns clicks into Herdr commands.
    Owns
    Layout, wrapping, the rename control.
    Delegates
    Grouping to Session list model; renaming to Herdr tab.rename; focusing to Herdr pane.focus; which sessions are under Done to Done ledger.

    Done ledger

    Responsibility
    Decides which sessions are under Done: a session that is not working and whose finished turn is above the turn its nerd-herd.handled label records.
    Owns
    The rule for Done, and the starting point for a session with no label.
    Delegates
    Nothing. Data in, data out.
    Input terminals()
    Herdr's core terminals: address, status, turn, and labels.
    Output Set<address>
    The sessions under Done.

    Dismiss control

    Responsibility
    Shows Dismiss on the main pane while the focused session is under Done, and handles the dismiss key.
    Owns
    The button, the key, and the label it writes.
    Delegates
    Whether the focused session is under Done to Done ledger; storing the dismissal to herdr-core, through hc label <terminal> nerd-herd.handled=<turn>.

    Validation Boundaries
    • Herdr’s agents, spaces, and terminals come typed from herdr.d.ts. An agent’s title is text the agent chose, so the row shows it as text and never interprets it.
    • A session name typed by the user goes to Herdr’s tab.rename, which owns its rules; an empty name returns the tab to its automatic name.
    • The nerd-herd.handled label is external data: another Herdr window, another nerd-herd version, or a hand edit with hc label may have written it. Done ledger reads it as a whole turn number; any other value counts as no label.

    Ambiguity Resolution

    "Session" means a Herdr tab that runs an agent. Herdr's Agents section already labels each row from its tab name when the tab is named, so renaming a session means renaming its tab (tab.rename), which also follows the standing rule to use Herdr's own features.

    The shipped agents mod belongs to Herdr. Herdr’s guide says to copy shipped mods with mod.clone before changing them, so nerd-herd’s Agents mod goes into a copied layout and the user’s main layout stays as it is.

    "Done" in this spec means a session that finished a turn Dannel has not dealt with, by dismissing it or replying. Herdr's own done means a session that finished while nobody was looking at it, and it ends when someone looks. The Agents mod shows nerd-herd's meaning under the Done header. Herdr's done and idle both feed it, and its Idle header holds the rest.

    End-to-end tests share the harness the Spaces spec researches (its question “End-to-end test harness”).
